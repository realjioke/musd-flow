## Project overview

MUSD Flow turns MUSD from "a token in a wallet" into a payment experience people can
actually use with each other:

- **Multichain MUSD portfolio** with verified contract reads on Mezo, Ethereum, Base
  and an explicit, sourced support matrix (BNB = unsupported for MUSD, documented).
- **Send** with honest preflight checks (token balance, gas cost, gas balance),
  a review screen, and receipts displayed from actual chain data.
- **Shareable payment requests** (link + QR) whose status is only ever updated by
  server-side verification of the payer's real MUSD `Transfer` event.
- **MUSD Circles** — group savings for rent, tuition, business goals, etc.,
  with on-chain verified, idempotent contribution tracking. The platform is fully
  non-custodial: contributions are direct transfers between member wallets to a
  creator-controlled destination. MUSD Flow holds no keys and no funds.
- **Mezo-first design**: Mezo is the default network choice in flows, the hub page
  surfaces MUSD's Bitcoin-backed story, the official testnet faucet, the MEZO token's
  documented bridging, and veMEZO locking docs — without inventing token utility.

## How MUSD adoption and MEZO utility grow

1. Payment requests let an MUSD holder get paid by *anyone* — the payer lands on a
   no-wallet-required page explaining MUSD, then connects and sends. Every fulfilled
   request is a new real MUSD transaction on Mezo or a bridged network.
2. Circles create standing, recurring MUSD flows (community savings is one of the
   strongest durable demand patterns for a stablecoin), denominated in MUSD and
   settled on Mezo.
3. MEZO utility grows through balance visibility, documented bridge/veMEZO paths, and
   the verified integration matrix that routes developers and users to official
   resources — our integration evidence is auditable.
